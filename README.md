# homebrew-tap

Homebrew tap for [feedpaper](https://github.com/jonashonecker/feedpaper) — build an
ePub newspaper from your unread Feedbin blog posts.

## Install

```bash
brew install jonashonecker/tap/feedpaper
```

Installing through Homebrew avoids the macOS "unidentified developer" warning, so
there's no need to clear the download quarantine by hand.

Currently ships an Apple Silicon (arm64) macOS binary.
